## 首期完成定义

首期系统最终应能：

- 从 BaoStock 与 AKShare 多个独立 upstream 更新并发布通过质量门的日线版本。
- 旧 XTQuant 日线候选已完成只读评估并以冻结拒绝结论处置（ADR-027）：不修改旧项目、
  不恢复 QMT 依赖，`XTQUANT_LEGACY` 不进入发布链。
- 计算可核对因子，训练简单基线模型。
- 生成周度 Top 30 目标组合和人工调仓计划。
- 使用 Qlib 快速研究并由 Backtrader 正式验收。
- 在本机 Web 查看数据、任务、模型、回测和计划。
- 通过文件或人工录入对账，不自动下单。

状态必须由实际运行和验收证据驱动；代码存在或合成测试不能证明真实数据覆盖。
