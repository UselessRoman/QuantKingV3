```text
S1-07K1 AKShare 东财/腾讯/新浪适配 + 小样本实测
    → S1-07K2 A/B 互验 + C 异常仲裁 + 生产 EOD
```

Stage 1 不再包含 XTQuant、QMT、券商账号、机构级签名授权链、17 类 purpose 或 24 单元证据矩阵。

## 首期完成定义

首期系统最终应能：

- 从 AKShare 的多个独立上游更新并发布通过质量门的日线版本。
- 计算可核对因子，训练简单基线模型。
- 生成周度 Top 30 目标组合和人工调仓计划。
- 使用 Qlib 快速研究并由 Backtrader 正式验收。
- 在本机 Web 查看数据、任务、模型、回测和计划。
- 通过文件或人工录入对账，不自动下单。

状态必须由实际运行和验收证据驱动；代码存在或合成测试不能证明真实数据覆盖。
