## 首次可监督使用定义（Stage 5）

- 发布可追溯、通过多源质量门的 A 股日线版本。
- 生成无前视、可复算的研究输入、股票池、标签和因子。
- 训练简单基线模型并形成版本化预测。
- 生成周度目标组合和人工调仓计划。
- 使用 Qlib 快速研究并由 Backtrader 正式验收。
- 在本机 Web 查看数据、任务、模型、回测和计划。
- 通过文件或人工录入完成对账，不自动下单。

## 核心系统完成定义（Stage 6）

- 四个连续历史周加速演练无血缘、幂等或账务断裂。
- 中断、部分成交、重复导入和程序重启能够恢复并解释。
- 新增模型、回测、计划、成交和策略账可由既有备份机制真实恢复。
- 用户可按操作手册完成 EOD、周度调仓、成交确认、对账和失败处理。

Stage 7 是核心闭环后的单域按需扩展，不阻断首次可监督使用或核心系统完成。
