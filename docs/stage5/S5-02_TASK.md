# S5-02 任务卡：计划批准、成交确认、策略账与对账

状态：未开始、未授权。

## 目标与依赖

- Stage：5。
- 依赖：S5-01 已验收。
- 目标：将人工批准和人工交易事实安全写入一个模拟策略账，并显示可解释差异。

## 范围

- 计划状态用简单枚举和命令转换表达：草稿、待确认、已批准、已完成、已取消；部分成交和过期
  作为稳定结果/原因，不建设工作流引擎。
- 批准前再次运行风险门；`BLOCK` 不可覆盖，允许覆盖的 `WARNING` 必须填写原因。
- 已批准计划导出一个规范 CSV，供用户在券商客户端手工参考，不包含券商指令协议。
- 支持一个规范成交 CSV 和人工录入；原始文件或摘要只追加，使用稳定成交 ID/复合键幂等。
- 只做证券、方向、数量、价格/日期等确定性精确匹配；不确定项保持待确认。
- 用户确认匹配后创建不可变 `Fill`，按确定性账务规则更新一个 `StrategyLedger`。
- 增加最小人工公司行动确认：依据显式事件/规则和用户提供的事实录入现金红利、送转的非成交
  调整，先进入待确认区，确认后才更新策略账。复用 S4-01 的事件算术和生效顺序，不伪造 `Fill`。
- 非成交记录绑定账户、证券、事件键、有效时点、现金/股数/应收权益变化、来源和确认审计；
  不确定项保留待处理。已有持仓涉及未解释事件时阻断依赖该账务的正式计划批准，不能覆盖快照消差。
- 对账比较最新 `BrokerSnapshot` 与策略账的现金/持仓，记录差异和用户处理决定。

## 输出

- 计划批准/取消/替换、规范导出、成交导入/人工录入和确认命令。
- 一个策略账、对账摘要和待确认列表。
- 现金红利/送转的人工非成交确认命令和只追加记录，复用现有审计及单策略账，不增加券商格式。
- `docs/stage5/S5-02_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 已批准计划不可修改；替换创建新版本并关联旧计划。
- 重复导入和重复确认不重复记账；金额、费用、持仓和现金守恒。
- 部分成交、重复成交、零股、取消、未匹配和快照差异 fixture 通过。
- 自动匹配只生成建议，未经用户确认不会创建 `Fill` 或更新策略账。
- 复用 S4 现金红利/送转手算预期：待确认不记账，确认后现金/应收权益/股数守恒；重复确认、
  从新文件重复录入同一事件不重复记账，未知或矛盾事实阻断，历史已确认记录不可修改。
- 所有写命令有幂等键、并发版本检查和审计。

## 禁止项

- 不解析多券商自定义格式，不做模糊/机器学习匹配。
- 不登录、读取或控制券商客户端，不调用下单/撤单接口。
