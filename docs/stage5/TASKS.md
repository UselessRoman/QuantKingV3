## 共同实施规则

- 首版只有一个策略、一个账户标识和一个模拟策略账，不建设多账户/多策略平台。
- 金额、费用和账务使用 `Decimal` 或冻结定点语义；证券数量使用整数。
- 所有命令使用幂等键、并发版本检查和审计；已批准计划、确认成交和策略账只追加。
- 文件只接受受管理上传对象和固定 schema，不接受任意本地路径。
- 页面和 API 只围绕首次闭环需要的读写操作，不建设券商适配器或复杂对账工作台。
