# S3-02 任务卡：Ridge、LightGBM 与预测版本

状态：未开始、未授权。

## 目标与依赖

- Stage：3。
- 依赖：S3-01 已验收；输入为显式 Stage 2 版本和冻结时间切分。
- 目标：用基础 10 因子训练两个固定基线并发布可复算 `PredictionSet`。
- 正式数据根读取和模型/预测写入须单独授权。

## 范围

- Ridge 使用一个冻结正则参数配置；标准化参数只在训练区间拟合。
- LightGBM 使用一个冻结轻量配置和随机种子；不运行网格、贝叶斯或手工多轮搜索。
- 两个模型消费相同训练/验证/测试切分、股票池和主标签，模型只输出证券分数。
- 每个实验保存输入版本、特征顺序、参数、随机种子、指标、预测、模型文件、日志和 SHA。
- 使用受管理格式/目录加载模型，加载前验证 manifest 和 SHA；不接受任意路径 pickle。
- 应用层提供显式实验和预测的有界摘要查询，本任务不建设页面。

## 输出

- 一个 Ridge `ExperimentRun`、一个 LightGBM `ExperimentRun` 及对应模型 artifact/`PredictionSet`。
- 失败保留、内容幂等、安全加载和只读查询实现。
- `docs/stage3/S3-02_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 合成线性样例验证 Ridge 方向；非线性固定样例验证 LightGBM 输出稳定性。
- 标签列或未来统计进入特征时测试必须失败。
- 重复冻结输入产生相同预测键、顺序和冻结容差内分数；随机种子和库版本进入 manifest。
- 第三方训练/加载异常转换为稳定错误，失败任务不发布 artifact。
- 只报告数据/分数层指标，不生成 Top-N 组合或回测收益。

## 禁止项

- 不进行参数搜索、模型集成、自动选择、自动批准或自动重训。
- 不实现组合、风险、回测和正式模型启用。
