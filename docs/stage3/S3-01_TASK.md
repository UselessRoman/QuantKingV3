# S3-01 任务卡：时间切分、对照标签与实验合同

状态：未开始、未授权。

## 目标与依赖

- Stage：3。
- 依赖：Stage 2 已完成并存在显式正式研究版本。
- 目标：冻结无泄漏的训练/验证/测试语义和最小实验产物，不训练正式模型。

## 范围

- 冻结训练、验证、测试日期，按每条样本的实际入场/标签终点判断切分资格并设置隔离；禁止随机切分。
- 以 Stage 2 相同入场口径增加 20 日对照标签，精确冻结端点、窗口末端和不可成交空值原因。
- 主标签与 20 日对照分别记录可用样本掩码，不能把主标签短隔离直接用于对照评价；需要共同样本
  比较时使用两者合法样本交集并披露覆盖变化，20 日标签缺失不剔除主标签训练合法样本（审阅 R4）。
- 冻结基础 10 因子的稳定顺序，以及 Ridge 标准化和 LightGBM 缺失处理规则。
- 定义 `ExperimentRun`、模型 artifact 和 `PredictionSet` manifest，复用统一版本/发布机制。
- 冻结 Stage 3 指标：IC、Rank IC、ICIR、覆盖、分布/相关性和时间分段稳定性。
- 同时冻结候选验证/拒绝标准和证据要求，不能看到正式实验结果后为获得候选而放宽标准。
- 定义简单模型状态转换：`草稿 → 已训练 → 已验证/验证失败 → 已批准`；本任务不实现通用工作流。

## 输出

- 时间切分和隔离规则、20 日对照标签、实验 schema 与固定 fixture。
- 合成 `ExperimentRun`/`PredictionSet` manifest 和安全模型 artifact 合同。
- `docs/stage3/S3-01_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 修改切分边界之后的数据不影响之前特征；标签不跨越声明窗口或隔离区。
- 覆盖主标签终点合法但 20 日标签越界、节假日改变周度端点、末端未成熟样例；两类样本资格
  分别验证，跨界标签不得参与相应评价，合法主标签样本仍可训练。
- 任何可学习预处理只读取训练区间，测试可通过恶意未来极值捕获泄漏。
- 推理 schema 在类型和运行时均不含标签。
- manifest 指纹忽略运行时间/临时路径，但包含所有决定结果的输入。
- 默认离线测试不读取正式数据根；真实版本只读检查另行授权。

## 禁止项

- 不训练 Ridge/LightGBM，不实现 Alpha158、组合、回测或页面。
- 不建设超参数搜索、实验数据库平台、审批角色或自动重训。
