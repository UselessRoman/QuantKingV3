# S2-04 任务卡：Qlib 全量视图、最小检查页与 Stage 2 终验

状态：已规划、未开始、未授权。

## 目标与依赖

- Stage：2。
- 依赖：S2-01～S2-03 均已验收，离线测试通过，正式逻辑版本可由显式父版本读取。
- 目标：把 Stage 2 研究链映射为可删除重建的 Qlib 全量视图，提供一个人工检查入口，并以一次
  有界正式构建关闭 Stage 2。

## 授权边界

- Qlib 适配、页面、API 和合成测试默认全离线。
- 正式运行前先生成零外部 I/O dry-run；真实网络、正式数据根写入和失败后的重跑分别授权。
- 只读终验不得改变正式数据根；完整质量门默认不访问网络。

## 范围

### 1. Qlib 全量派生视图

- 在 `research/adapters` 映射交易日历、证券集合、连续研究 OHLCV/amount、股票池、主标签和
  10 个基础因子；领域和应用层不导入 Qlib。
- 只实现从显式父版本开始的全量构建。`QlibViewVersion` 写入新临时目录，文件集合和 manifest
  一致后原子发布；已发布目录不可修改。
- 锁定 Qlib 版本并转换第三方异常；共同定义字段在确定性样本达到冻结容差。
- 不实现增量构建、增量/全量校准、Alpha158 或模型数据处理器。

### 2. 一个最小研究检查页

- 复用现有 DataCenter/任务能力，提供一个有界页面查看：研究输入覆盖与缺口、日期×证券股票池
  原因、主标签端点/空值原因、10 个因子定义、覆盖/缺失和基础分布。
- API 只接受显式版本、日期/证券过滤和有界分页；浏览器不接收绝对路径、供应商载荷或全市场矩阵。
- 交付一条关键 E2E：选择显式版本，检查一条股票池/标签样本和一个因子摘要。

### 3. 正式构建与轻量只读复验

- dry-run 冻结父版本、证券集合/SHA、日期范围、来源调用预算、规则/代码版本、精确写入目录和
  `ResearchInputVersion → UniverseVersion/LabelVersion/FactorSetVersion → QlibViewVersion`
  预期产物；不得使用无界范围描述。
- 正式 Job 按父子顺序执行；任一步失败即停止且下游不启动。
- 只读复验直接使用 manifest 和实际文件，检查父引用、文件集合、行数、内容 SHA、逐证券覆盖、
  标签端点和因子定义顺序；不复制业务计算或建设第二套 verifier 控制面。
- 用相同冻结输入完成一次全量重建幂等检查。

## 输出

- Qlib 全量适配器和 `QlibViewVersion`。
- 一个最小研究检查页、对应 API 和一条关键 E2E。
- 正式 dry-run、获授权后的完整研究链和轻量只读复验证据。
- `docs/stage2/S2-04_ACCEPTANCE.md` Stage 2 最终验收记录。

## 测试与验收

- Qlib 字段、日历、instrument、数据集和第三方错误契约测试通过。
- Qlib 视图可从零重建且内容摘要稳定；父版本和已发布目录保持不变。
- 页面/API 有界查询、错误路径、前端测试和一条关键 E2E 通过。
- 临时目录、manifest、`COMPLETE`、原子发布、失败保留和幂等集成测试通过。
- 运行 `scripts/quality.ps1` 完整离线门禁并记录实际结果；Markdown 链接和 `git diff --check` 通过。
- [验收矩阵](ACCEPTANCE.md) 全部关闭后才能更新路线图；完成不会自动授权 Stage 3。
