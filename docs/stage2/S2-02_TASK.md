# S2-02 任务卡：point-in-time 研究输入

状态：已规划、未开始、未授权。

## 目标与依赖

- Stage：2；开头包含日常 EOD 的 Stage 1 维护子步骤（审阅 R1）。
- 依赖：S2-01 已验收并冻结首次范围、来源政策、schema 和 fixture。
- 输入：显式 `PUBLISHED DatasetVersion`、版本化交易日历和 S2-01 规则。
- 目标：在有界正式范围内发布可复算的 `ResearchInputVersion`，供股票池、标签和因子共同消费。

## 授权边界

- 适配器、领域逻辑和合成发布测试默认全离线。
- 补充真实日线或参考字段的网络调用必须按冻结范围、调用预算和硬超时单独授权。
- 正式数据根的新版本写入单独授权；失败后的新 Job 或扩大范围不复用原授权。

## 范围

### 0. 日常 EOD 入口维护（R1）

- 先用临时数据根、合成日历和拒绝联网网关，从正常 CLI/API 入队并运行 Worker，复现
  `CALENDAR_REFERENCE_MISSING`；验收不得只停在 `PENDING`。
- 让日常 CLI/Web 复用同一有界执行合同，把显式 `PUBLISHED` 日历版本/SHA、证券日期范围和预算
  冻结到 Job，并由 Worker 读取相同输入。复用既有 manifest、发布和幂等服务，不恢复历史一次性授权。
- 缺失、越界、未发布或 SHA 不符的日历在供应商调用前拒绝；现有 EOD 页提供必要的输入/失败反馈，
  不新建页面。没有可用日历时给出有界新版本发布的受控路径，外部读取/写入仍单独授权。
- 即使本次父日线覆盖够用也须完成本项；离线入口回归通过前不得执行任何新正式日线采集。

### 1. 父日线资格与有界扩展

- 检查父日线是否覆盖 S2-01 冻结范围内的规范证券集合和日期窗口。
- 覆盖不足时，只复用 Stage 1 A/B/C 采集、仲裁、质量和原子发布服务生成新
  `daily_bar_unadjusted DatasetVersion`；不新增日线 schema 或第二条抓取逻辑。
- 新父版本未通过既有质量门前，不启动研究输入发布。

### 2. 三个必要参考合同

- `security_lifecycle`：证券、交易所/板块、上市日、退市日和有效区间。
- `security_status_daily`：ST/`*ST`、退市整理、停牌和状态可用时间。
- `adjustment_factor_daily`：生效日、point-in-time 累积因子、来源和规则版本。
- 按 S2-01 冻结的字段级来源政策保存来源、抓取/披露时间、修订和交叉检查结果。
- 将 S2-01 合格的最小公司行动事实及其来源引用随研究 manifest 交接，使用同一发布机制；
  仅执行字段的缺失单列为执行覆盖缺口，未知不能表示“无事件”。不实现公司行动平台或策略账。

### 3. 研究输入发布

- Stage 1 Warehouse 保持只读；连续研究 OHLC、未复权 volume/amount、生命周期和状态引用只写入
  新的 `ResearchInputVersion`。
- 复权采用固定历史锚点或等价追加稳定表达；未来公司行动不得改变生效日前结果。
- 质量检查只实现当前需要的有效区间、交易日历矛盾、非正因子、异常跳点、公司行动连续性、
  逐证券覆盖和来源证据，不建设通用证券主数据或公司行动平台。
- 使用通用研究 manifest 和现有 Job/日志/原子发布服务；相同输入和规则全量重建内容幂等。

### 4. 最小读取能力

- 应用层提供显式版本的覆盖、缺口、逐证券状态/复权摘要和有界明细查询。
- 本任务不建设新页面；S2-04 再把稳定读取能力接到一个最小研究检查页。

## 输出

- 必要适配器、领域规则、应用服务和持久化实现。
- 一个合成发布版本及其失败保留、幂等和只读查询证据。
- 获得正式授权后，一个有界 `ResearchInputVersion`。
- `docs/stage2/S2-02_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 正常 CLI/API → Worker → 合成 `PUBLISHED` 路径通过，重复请求幂等；Web 现有 EOD 控件的
  输入绑定/失败反馈有定向测试。合法日历能执行，缺失/错误日历均在零供应商调用时拒绝。
- R1 维护及研究输入结果分别记录到本任务验收；入口修复不降低日历、两源共识或原子发布门槛。
- 公司行动事实/执行缺口可查询、可追溯，后续修订只建新版本，不以累计因子推算现金与股数。
- 当前名称或当前列表不能回填历史；未来状态和未来公司行动扰动不改变生效日前结果。
- 缺状态、来源冲突、时点不明、非法因子或覆盖不足会隔离并阻止受影响范围发布。
- 合成发布、失败保留、显式父版本、全量幂等和只读查询集成测试通过。
- 代表性真实样本与 S2-01 资格结论一致；来源资格失效时停止正式发布并形成可复验结论。
- 定向测试、本任务涉及的后端门禁及现有 EOD 控件前端检查通过；不以新增研究页面或 Qlib
  作为本任务完成条件。

## 禁止项

- 不修改 Stage 1 已发布数据。
- 不实现股票池、标签、因子、Qlib、模型或研究仪表盘。
- 不因数据不足扩大为 Stage 7 财务、行业、估值或指数成分平台。
