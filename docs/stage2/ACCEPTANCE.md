## A. 前置与范围

- [ ] Stage 1 已最终验收，父 `DatasetVersion` 明确且处于 `PUBLISHED`。
- [ ] 正式市场、证券、日期范围和排除项有规范清单及 SHA；北交所等未覆盖范围显式列出。
- [ ] S2-01 的复权、状态、标签、流动性和不可成交语义已由用户确认并有固定样例。
- [ ] 旧项目指定候选逐项形成 `ADAPT/REWRITE/DISCARD` 结论；旧根未修改且无目录整体复制。

## B. point-in-time 研究输入

- [ ] 生命周期、ST/`*ST`、退市整理、停牌和复权因子均有字段、来源、可用时间和修订合同。
- [ ] 父日线覆盖声明研究窗口内全部曾上市证券；若发生覆盖扩展，只复用 Stage 1 已验收管线且
  新 `DatasetVersion` 独立通过原有仲裁、质量与发布门。
- [ ] 研究范围内历史退市证券未因使用当前上市列表而消失；逐证券状态/复权覆盖可查询。
- [ ] 未来状态和未来公司行动扰动不改变生效日前的研究输入；供应商修订只产生新版本。
- [ ] 单源、冲突、缺口、非法因子或时点不明会隔离并阻止受影响范围发布。
- [ ] `ResearchInputVersion` 可从显式父版本重复生成相同业务内容摘要。

## C. 股票池与标签

- [ ] 动态股票池逐日记录纳入/排除原因，覆盖 120 交易日、ST、停牌、退市整理、历史窗口和流动性。
- [ ] 流动性窗口只读 T 日及以前数据；阈值和最少观测数进入版本。
- [ ] 周度主标签和 20 日对照标签用固定交易日历样例证明精确执行下标。
- [ ] 明确不可成交端点产生稳定空值原因，不前向填充或顺延到声明窗口外。
- [ ] 未来扰动、标签窗口和推理不加载标签三类防泄漏测试通过。

## D. 因子与 Qlib

- [ ] 15 个基础因子全部注册，公式、窗口、可用时间、缺失/零分母规则和人工样例齐全。

- [ ] Alpha158 通过同一注册和版本入口，并记录与基础因子的语义差异。
- [ ] Qlib 视图由显式父版本全量重建成功，已发布目录未被修改。
- [ ] 兼容增量与全量重建在固定样本一致；不一致会失败并回退新全量 Job。
