- 外部授权：默认全离线；若读取 `E:\QuantKing` 中指定旧文件，须单独只读授权并证明旧根未修改。

### 范围

  `scripts/convert_to_qlib.py`、`strategy/alpha_factors.py` 和 `docs/RESEARCH_WORKFLOW.md`；逐项给出
  `ADAPT/REWRITE/DISCARD` 结论。旧 `strategy/qlib_model.py` 属于 Stage 3，不在本任务读取或迁移。

## S2-02：point-in-time 状态、复权与研究输入版本

### 目标与依赖

- 依赖：S2-01 已验收；输入必须是显式 `PUBLISHED DatasetVersion`。
- 目标：补足 Stage 1 未复权日线不能单独提供的历史状态与复权语义，发布
  `ResearchInputVersion`。
- 外部授权：适配器开发和合成测试离线；代表性真实来源资格验证、正式数据根写入分别授权。

### 范围

- 只实现三个必要数据合同：
  - `security_lifecycle`：证券、交易所/板块、上市日、退市日及有效区间；
  - `security_status_daily`：ST/`*ST`、退市整理、停牌及状态可用时间；
  - `adjustment_factor_daily`：生效日、point-in-time 累积因子、来源和规则版本。
- 先执行父日线版本资格检查。若它没有覆盖冻结研究窗口内全部曾上市证券，复用已验收的 Stage 1
  A/B/C 采集、仲裁、质量和原子发布服务生成一个新 `daily_bar_unadjusted DatasetVersion`；
  不新增日线 schema 或第二条抓取逻辑，覆盖扩展未通过前不得发布研究输入。
- S2-01 冻结各字段的来源路线、单位、修订和一致性规则。能沿用 BaoStock/腾讯/新浪的部分仍
  分别留证；不能满足两源和时点语义的字段保持隔离，不得靠单源猜测发布。
- Stage 1 Warehouse 保持只读且不可变；在研究层派生同时包含未复权事实、连续研究 OHLC、
  volume/amount 和状态引用的 `ResearchInputVersion`。
- 复权因子使用固定历史锚点或等价的追加稳定表达；未来才生效的公司行动不得改变此前的研究
  收益/特征。对供应商修订则创建新版本并保留父血缘，不覆盖旧版。
- 质量门检查有效区间重叠、状态与交易日历矛盾、复权跳点、非正因子、公司行动边界连续性、
  逐证券覆盖和来源证据。
- DataCenter 增加研究输入的有界覆盖摘要和缺口/隔离原因，不暴露供应商载荷或绝对路径。

### 测试与验收

- 契约/性质测试证明：当前名称或当前上市列表不能回填历史；未来状态和未来公司行动扰动不改变
  生效日前结果；缺状态/单源冲突/非法因子会阻止发布。
- 合成发布、失败保留、相同输入幂等、显式父版本和只读查询集成测试通过。
- 代表性真实样本至少覆盖一例实际公司行动、ST 状态变化、停牌、上市和退市边界；资格失败时
  停止正式范围扩大并形成可复验阻断结论。
- 最小 DataCenter API、前端状态和 E2E 流程在本任务验收，不推迟到 S2-06。

## S2-03：动态股票池与执行对齐标签

### 目标与依赖

- 依赖：S2-02 已验收的 `ResearchInputVersion`。
- 目标：发布可解释的 `UniverseVersion` 与 `LabelVersion`，并证明无前视。
- 外部授权：使用合成或已授权发布版本离线计算；正式数据根的新版本发布另行授权。

### 范围

- 每个交易日逐证券输出纳入结果和稳定原因集合，首版至少检查：生命周期有效、上市满 120 个
  交易日、非 ST/`*ST`、非退市整理、当日未停牌、必要历史窗口完整、流动性达标。
- 上市天数按版本化交易日历计数；停牌日是否计入“上市满 120 交易日”的年龄由 S2-01 样例
  明确，不用自然日近似。
- 流动性只使用 T 日收盘时已知的过去窗口，不使用未来成交额或全样本阈值。阈值和最少有效观测
  数进入规则版本。
- 主标签按冻结周度日历计算下一执行参考价到下一调仓执行参考价的 open-to-open 收益；20 日
  对照标签使用相同起点和冻结的 20 持有期终点。close-to-close 只可作为显式对照列。
- 入场停牌/一字涨停或出场停牌/一字跌停等明确不可成交时标签为空并记录端点原因；不把价格
  前向填充、不顺延到声明窗口外。普通触及涨跌停但日线不能证明不可成交时保留执行价假设标志。
- API/因子研究页先提供一个有界“日期 × 证券”检查视图，展示纳入/排除原因、标签端点和空值
  原因，供人工核对。

### 测试与验收

- 固定样例精确覆盖周末、法定节假日、调仓周、窗口末端、停牌、一字涨跌停和状态切换。
- 性质测试证明：修改 T 之后的状态/价格不改变 T 及以前股票池；修改标签终点之后的数据不改变
  该标签；标签端点不可越过 manifest 声明窗口。
- 推理读取接口在类型和运行时均不提供标签列；特征与标签存储/查询边界分离。
- 页面/API 只接受显式版本和有界过滤，前后端及关键 E2E 通过。

## S2-04：因子注册与基础审计集

### 目标与依赖

- 依赖：S2-03 已验收；因子只读取 `ResearchInputVersion` 与 `UniverseVersion`。
- 目标：以简单公式交付 15 个可人工核对的 `FactorSetVersion`，不训练模型。

### 首版因子

| 类别 | 因子 |
|---|---|
| 收益 | `ret_1`, `ret_5`, `ret_20`, `ret_60` |
| 波动 | `volatility_20`, `volatility_60` |
| 趋势/位置 | `ma_gap_5`, `ma_gap_20`, `ma_gap_60`, `price_position_20` |
| 日内幅度 | `range_mean_20` |
| 量额 | `volume_ratio_5_20`, `amount_ratio_5_20`, `amount_log_mean_20` |
| 量价关系 | `price_volume_corr_20` |

收益、波动、均线和价格位置使用 S2-02 冻结的连续研究价格；volume/amount 保持 Stage 1 单位。
没有可靠流通股本前不把成交量代理命名为“换手率”。每个公式必须冻结收益形式、`ddof`、窗口
端点、最少观测、零分母和 NaN/无穷处理。

### 范围

- `FactorDefinition` 声明稳定 ID/版本、输入、窗口、可用时间、缺失规则、方向和人工核对方法；
  注册顺序和定义摘要进入版本指纹。
- 用受管理 Python 实现基础审计集；若表达式足够简单可同时记录 Qlib 等价式，但业务定义不由
  Qlib 对象反向决定。
- 原始因子值是正式输出。研究页可生成按日截面排名/标准分数用于诊断，但 Stage 3 才拥有按训练
  区间拟合的去极值、标准化和模型特征处理；本任务不建设通用处理器框架。
- 因子发布沿用临时目录、manifest、完整性检查和原子发布；相同输入/定义内容幂等。
- 因子研究页在本任务交付定义、版本、覆盖率、缺失原因和分布摘要，不等待 Qlib/Alpha158。

### 测试与验收

- 每个因子至少有一个手算夹具和窗口边界/缺失/零分母反例；15 个因子全部登记且顺序稳定。
- 未来价格、未来股票池或未来公司行动扰动不改变历史因子；被排除证券不会通过填充重新进入。
- 全量与分区计算在固定样本逐值一致；相同父版本重复构建得到相同内容摘要。
- API/页面只能查看显式版本的聚合与有界明细，前后端测试及 E2E 通过。

## S2-05：Qlib 派生视图、Alpha158 与研究诊断

### 目标与依赖

- 依赖：S2-04 已验收。
- 目标：证明 QuantKing 研究版本可被锁定 Qlib 稳定消费，并完成用于 Stage 3 之前的数据诊断。

### 范围

- 在 `research/adapters` 将交易日历、证券集合、连续研究 OHLCV/amount、股票池、基础因子和
  标签映射到可删除重建的 `QlibViewVersion`；领域/应用层不导入 Qlib。
- 先实现全量构建。只有父版本是严格追加、全部定义/日历/状态版本兼容且旧分区内容摘要不变时，
  才允许在新临时目录基于父 Qlib 版本增量构建；永不修改已发布目录。
- 增量构建在固定证券/日期样本与从零全量构建逐值和文件清单校准；不一致则本次失败并新建全量
  Job，不在同一失败目录修补。
- Alpha158 作为独立 `FactorSetVersion` 通过同一注册、父版本和 manifest 入口运行；记录字段
  映射、表达式、窗口、缺失和与基础审计因子的语义差异，不设为默认生产因子集。
- 因子研究页补齐 IC/Rank IC、分组收益、横截面相关性和基础集/Alpha158 对比。只计算 Stage 2
  数据诊断，不报告模型收益、组合绩效或回测结论。
- 大矩阵在后端聚合或分页；一次只运行一个研究构建 Job，实测资源不足后再考虑并行。

### 测试与验收

- 锁定 Qlib 版本的字段、日历、instrument 和表达式契约测试通过；第三方异常转换为稳定错误。
- Qlib 与 QuantKing 对共同定义因子在确定性样本达到冻结容差，差异有明确语义说明。
- 全量重建可复算；兼容增量、非兼容全量回退、失败目录保留和父版本不可变测试通过。
- 覆盖/分布/IC/分组收益/相关性 API、前端和关键 E2E 通过，浏览器不接收全市场 DataFrame。

## S2-06：正式构建、独立复验与 Stage 2 终验

### 目标与依赖

- 依赖：S2-01～S2-05 均已独立验收，全部离线质量门通过。
- 目标：在明确证券与日期范围内生成一条完整正式研究链，并用独立只读复验关闭 Stage 2。
- 外部授权：先生成零外部 I/O dry-run；真实网络、正式数据根写入和任何失败重跑分别授权。

### 范围

- dry-run 冻结父数据版本、证券集合/SHA、日期范围、来源调用上限、规则与代码版本、预计分区、
  精确写入目录和所有预期产物；范围不得只写“全 A 股”或“全部历史”。
- 正式 Job 顺序发布 `ResearchInputVersion → UniverseVersion/LabelVersion → FactorSetVersion →
  QlibViewVersion`；任一步失败即停止，下游不得启动。
- 独立 verifier 从 manifest 和实际文件重算父血缘、集合/行数守恒、SHA、逐证券覆盖、未来扰动
  样本、标签端点、因子定义顺序及 Qlib 映射；只读复验不得改变数据根。
- 以相同冻结输入执行内容幂等检查；选取固定追加样本执行一次增量与全量校准。若不具备真实追加
  条件，用已发布版本的受控离线派生副本演练，不为制造证据访问额外网络。
- 在 Web 完成显式版本的状态/标签样本/因子诊断关键流程，并运行完整质量门。
- 形成 `docs/stage2/S2-06_ACCEPTANCE.md`，只在 [验收矩阵](ACCEPTANCE.md) 全部通过后更新
  `ROADMAP.md` 和阶段状态。

### 禁止项与验收

- 不训练 Ridge/LightGBM，不创建模型生命周期，不运行 Qlib/Backtrader 回测，不开始 Stage 3。
- 不因单次真实任务成功跳过来源语义、无前视、可复算、Web 或完整门禁。
- 失败任务和目录保持失败状态；重跑创建新 Job、新输出和新授权。
- 独立验收报告必须列出明确未覆盖范围，尤其是北交所或研究窗口外历史，不得把缺口写成已支持。
