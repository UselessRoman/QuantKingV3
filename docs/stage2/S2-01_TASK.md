# S2-01 任务卡：首次范围、来源资格与固定样本

状态：2026-09-08 已授权本地开发，2026-09-09 已批准首轮有界来源探针；正式资格待证据。
实施与实际验收见 [S2-01_ACCEPTANCE.md](S2-01_ACCEPTANCE.md)。

## 目标与依赖

- Stage：2；附带已有 Stage 1 来源边界的工程门禁维护（审阅 R3）。
- 依赖：Stage 1 已最终验收；本任务已取得本地开发授权，外部操作继续按下述边界执行。
- 目标：在批量编码前确认首个研究范围确实可获得所需数据，并冻结会影响下游的最小研究语义。
- 完成后形成合同、资格结论、离线样例及 R3 门禁修复，不写正式研究数据。

## 授权边界

- 合同、fixture 和合成测试默认全离线，不访问正式数据根。
- 来源资格探针需要真实网络时，必须先给出证券、日期、endpoint、调用次数、超时和输出目录，
  获得一次有界授权；探针只写仓库内证据，不写 `E:\QuantKingV3Data`。
- 默认不读取 `E:\QuantKing`。只有用户明确选择复用某个候选文件时，才建立单独只读审计任务。

## 范围

### 0. 来源门禁维护（R3）

- 先以离线正负样例复现 BaoStock 被误判为退役依赖，再将其与 AKShare 一起限定到 `data/adapters`。
- 同步检查器和边界测试；业务/研究/组合/Web 层继续禁止直接导入供应商 SDK，QMT/XTQuant
  继续拒绝。覆盖当前静态导入及字面量动态加载方式，不扩大成通用动态导入分析框架。
- 在任何来源适配器变更验收前关闭本项，证据合并到本任务验收，不新建通用依赖治理框架。

### 1. 冻结首次正式范围

- 给出市场、板块、证券集合生成规则、起止交易日、排除项、预计证券数/行数和规范集合 SHA。
- 优先评估“沪深、最近三个完整自然年加当年冻结截止日、窗口内曾上市证券”的候选；若来源调用
  或本机资源不适合，缩小日期或证券范围并显式记录，不降低时点语义或伪称全市场覆盖。
- 绑定显式 Stage 1 `PUBLISHED DatasetVersion` 候选；记录当前两证券样本与正式研究范围之间的缺口。
- 分别列出取数/预热、可用信号、标签尾部窗口，并计入证券、日期和调用预算，不能只冻结信号区间。

### 2. 先验证来源可得性

- 对 `security_lifecycle`、`security_status_daily`、`adjustment_factor_daily` 分别验证字段、单位、
  可用时间、历史深度、修订行为、空结果和错误语义。
- 日线仍使用 ADR-021 的 A/B/C 路线。研究参考字段按 ADR-029 选择权威来源，或主来源加独立
  日历/价格连续性/第二来源交叉检查；不得机械假设腾讯或新浪具备相同参考字段。
- 代表性探针至少覆盖实际公司行动、ST 状态变化、停牌、上市和退市边界。任一必要字段不可得时，
  在进入 S2-02 前缩小范围、调整字段合同或形成明确阻断结论。
- 对 R2 另列分红/送转和除权参考价可用事实、来源及覆盖缺口；累计复权因子不得冒充现金/股数事件。
  研究复权所需事实不明仍阻断；仅执行用途字段缺失可以作为显式执行缺口交接，不能宣称可正式回测。

### 3. 冻结最小研究语义

- 冻结生命周期有效区间、ST/`*ST`、退市整理、停牌、复权因子的主键、可用时间和缺失语义。
- 冻结上市满 120 个交易日、流动性窗口、周度信号日和 open-to-open 主标签的精确下标。
- 冻结日线可证明不可成交的判定边界；日线不能证明时只记录执行假设，不扩张为 Tick 级判断。
- 冻结最小公司行动交接字段：事件键、证券、类型、披露/可用时间、权益登记/除权/到账或可卖日期、
  每股现金或股数比例、单位/税费口径和来源修订；缺字段明确标记，不从累计因子反推。
  区分连续研究价、未复权成交/估值价与交易规则参考价；Stage 4 才实现持仓和现金处理。
- 定义一套通用研究 artifact manifest，至少包含 `artifact_type`、版本 ID、父版本、范围、规则摘要、
  内容 SHA、代码/依赖版本和缺口；不为五类逻辑产物建立五套状态机或发布服务。

### 4. 固定样本

- 建立小型确定性 fixture，覆盖正常日、节假日、上市未满 120 交易日、ST、停牌、一字涨跌停、
  退市、公司行动、缺行和标签窗口末端不足。
- fixture 能人工逐行算出连续研究价格、股票池结果、周度主标签和至少一个滚动因子。
- 公司行动 fixture 包含现金红利和送转两类，给出独立手算现金/权益/股数预期供 Stage 4/5 复用；
  同时包含执行字段缺失的拒绝预期，本任务不执行回测或记账。

## 输出

- 首次范围与父版本资格清单。
- 研究参考字段来源资格报告和字段级来源政策。
- 可执行 schema、规则配置与确定性 fixture。
- 通用研究 artifact manifest 合同。
- `docs/stage2/S2-01_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 默认测试零网络、零正式数据根访问，且不依赖当前日期或供应商在线状态。
- BaoStock/AKShare 在适配器内允许、在业务层拒绝，QMT/XTQuant 仍拒绝；R3 修复及正负样例通过。
- schema、时间可用性、缺失/冲突和 manifest 指纹有契约测试。
- fixture 的手算预期与实现无关，未来状态/公司行动扰动的预期已明确。
- 所有会改变 S2-02 实现的决定已经冻结；未决定项保持阻断，不写“实现时再说”。
- 本任务验收不会自动授权 S2-02、全量网络调用或正式数据根写入。

## 禁止项

- 不实现批量研究输入、因子、Qlib、模型或页面。
- 不复制或运行旧项目代码。
- 不以单源猜测补齐未知历史，也不使用当前证券列表或当前名称回填过去。
