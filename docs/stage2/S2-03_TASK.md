# S2-03 任务卡：动态股票池、周度主标签与 10 个基础因子

状态：已规划、未开始、未授权。

## 目标与依赖

- Stage：2。
- 依赖：S2-02 已验收并发布显式 `ResearchInputVersion`。
- 目标：用最少且可人工核对的规则发布 Stage 3 可直接消费的股票池、主标签和基础因子。
- 外部授权：默认使用合成或已授权发布版本离线全量计算；正式数据根发布另行授权。

## 范围

### 1. 动态股票池

- 每个交易日逐证券输出纳入结果和稳定原因集合，至少检查：生命周期有效、上市满 120 个交易日、
  非 ST/`*ST`、非退市整理、当日未停牌、必要历史窗口完整和流动性达标。
- 上市时长按版本化交易日历计数；流动性只使用 T 日收盘时已知的历史成交额窗口。
- 规则、阈值和最少有效观测数进入 `UniverseVersion`；不建设规则图或通用 DSL。

### 2. 周度主标签

- 按 S2-01 冻结日历，从下一执行参考价到下一周调仓执行参考价计算 open-to-open 收益。
- 入场停牌/一字涨停或出场停牌/一字跌停等可由日线证明不可成交时，标签为空并记录稳定原因。
- 不前向填充，不顺延到声明窗口外；日线不能证明不可成交时保留执行假设标志。
- 特征读取和推理接口不暴露标签列。20 日对照标签移至 Stage 3。

### 3. 10 个基础因子

| 类别 | 因子 |
|---|---|
| 收益 | `ret_1`, `ret_5`, `ret_20`, `ret_60` |
| 波动 | `volatility_20` |
| 趋势 | `ma_gap_5`, `ma_gap_20`, `ma_gap_60` |
| 量额 | `volume_ratio_5_20`, `amount_log_mean_20` |

- `FactorDefinition` 冻结稳定 ID/版本、输入、窗口、可用时间、`ddof`、最少观测、零分母、NaN
  和人工核对方法。
- 因子使用 S2-02 的连续研究价格；volume/amount 保持 Stage 1 事实单位。
- 只发布原始因子值，不建设通用去极值、标准化或特征处理框架。
- 使用同一通用 manifest 和原子发布服务发布 `UniverseVersion`、`LabelVersion` 和
  `FactorSetVersion`；首版只实现全量计算。

### 4. 最小读取能力

- 应用层提供显式版本的股票池原因、标签端点/空值原因、因子定义、覆盖和基础分布摘要。
- 本任务不建设页面、IC、分组收益、相关性或 Alpha158；S2-04 只接入最小检查页。

## 输出

- `UniverseVersion`、周度主 `LabelVersion` 和 10 因子 `FactorSetVersion` 的实现与合成产物。
- 获得正式授权后，在冻结范围发布对应正式版本。
- `docs/stage2/S2-03_ACCEPTANCE.md` 实际验收记录。

## 测试与验收

- 固定样例覆盖周末、节假日、调仓周、窗口末端、停牌、一字涨跌停和状态切换。
- 修改 T 之后的状态/价格不改变 T 及以前股票池和因子；修改标签终点之后的数据不改变该标签。
- 推理路径在类型和运行时均不加载标签；被排除证券不会通过填充重新进入。
- 每个因子至少一个手算样例，并覆盖窗口边界、缺失和零分母反例。
- 相同父版本和规则全量重建得到相同业务内容摘要；失败不发布半成品。
- 定向测试和本任务涉及的后端门禁通过。

## 禁止项

- 不训练模型、不做时间切分、不实现 Alpha158。
- 不实现增量/分区构建或第二套因子计算框架。
- 不建设研究页面或完整因子评价平台。
