# Stage 2：研究数据、股票池、因子与标签

状态：实施路径已规划，尚未开始。Stage 1 的 S1-08R3 最终验收和完成提交是本阶段的硬前置；
本文档不构成 Stage 2 实施、真实网络、旧项目读取或 `E:\QuantKingV3Data` 写入授权。

## 阶段目标

以一个显式 `PUBLISHED DatasetVersion` 为父版本，建立可人工核对、无前视、可重复生成的研究
数据闭环：补足研究必需的复权和历史状态语义，按历史时点生成动态股票池与执行对齐标签，计算
一组小而清楚的基础因子，再导出 Qlib 派生视图并提供必要的研究诊断。

Stage 2 只证明“研究输入可靠且可复算”，不训练或审批模型，不实现组合、风险、回测、调仓或
自动运行。

## 最小主链

```text
显式 PUBLISHED DatasetVersion
    + 历史证券生命周期/状态
    + point-in-time 复权因子
    → ResearchInputVersion
    → UniverseVersion + LabelVersion
    → FactorSetVersion（基础审计集）
    → QlibViewVersion + Alpha158 基准
    → 覆盖/分布/IC/分组收益/相关性诊断
```

所有派生产物均在临时目录完成计算、校验和 manifest 后原子发布；失败任务保留但不发布。调用方
必须显式传入父版本 ID，不提供深层“自动选择 latest”。

## 复杂度边界

- 除复用 Stage 1 未复权日线合同外，只增加研究实际需要的三个数据合同：证券生命周期、逐日
  研究状态、逐日复权因子；不建设通用主数据平台、事件总线、工作流编排器或供应商审批系统。
- 沿用 Stage 0 的 `JobRun`、`JobEvent`、JSON Lines 和原子发布机制，不为因子另建平行任务或
  证据状态机。
- 研究数据以 Parquet/manifest 保存，SQLite 只保存版本元数据、任务和摘要，不保存全市场因子
  矩阵。
- Qlib 只出现在 `research/adapters`，其目录是可删除重建的派生视图，不拥有因子、标签、股票池
  或版本语义。
- 第一版只做 15 个可人工核对的量价因子；不做自动因子挖掘、特征商店、插件式 DSL、分布式
  计算、GPU 或超参数搜索。
- 页面只展示聚合指标和有界样本；不把全市场矩阵送入浏览器，不建设通用 BI。
- 初始市场边界建议先完成沪深 A 股闭环。S2-01 必须验证 Stage 1 父版本是否覆盖声明研究窗口
  内所有曾上市证券；若缺少历史退市证券，S2-02 只能复用已验收的 Stage 1 A/B/C 日线合同发布
  一个覆盖扩展的新 `DatasetVersion`，通过后才能研究，不能用当前上市列表缩小历史股票池。
  北交所在未取得同等质量的父数据和状态语义前不得冒充已覆盖，可在 Stage 2 完成后按同一合同
  另立扩展任务。

## 版本与血缘

只定义有当前 Stage 调用者的五类版本，不为 Stage 3/4 预建状态机：

| 版本 | 必须绑定的主要输入 |
|---|---|
| `ResearchInputVersion` | 父 `DatasetVersion`、证券范围、交易日历、生命周期/状态、复权规则与来源证据 |
| `UniverseVersion` | `ResearchInputVersion`、股票池规则版本、逐日纳入/排除原因 |
| `LabelVersion` | `ResearchInputVersion`、`UniverseVersion`、调仓日历、执行价与不可成交规则 |
| `FactorSetVersion` | `ResearchInputVersion`、`UniverseVersion`、因子定义顺序、公式/窗口/缺失规则 |
| `QlibViewVersion` | 上述父版本、字段映射、Qlib 版本、全量/增量构建方式与校准结果 |

manifest 的内容摘要只覆盖决定业务结果的规范内容；任务时间、临时路径等运行元数据不得破坏
相同输入的内容幂等性。已发布目录不可原地修改。

## 必须先冻结的研究语义

S2-01 必须用固定交易日样例和小型真实样本完成以下决定，必要时更新 `docs/DECISIONS.md`；在
此之前不得开始全市场正式构建：

1. **正式研究市场范围**：建议首版只验收沪深 A 股；北交所保持显式缺口，后续按同一合同扩展。
   日期范围内所有曾上市证券（含后来退市）必须进入父数据资格检查。
2. **复权口径**：建议保存未复权行情和独立 adjustment factor，并生成只依赖当时已生效公司
   行动的连续研究价格；禁止使用会因未来除权事件而重写历史值的“以最新日归一”价格作为
   唯一研究事实。
3. **周度主标签**：建议使用信号日收盘后确定的下一交易日开盘作为入场参考价、下一次周度
   调仓执行日开盘作为出场参考价；任一端明确不可成交时标签为空并记录原因，不顺延到窗口外。
4. **20 日对照标签**：使用同一入场口径和明确的第 20 个持有期结束执行价；精确下标由节假日
   和跨周固定样例锁定，不能用自然日或简单 `shift(-5/-20)` 猜测。
5. **流动性规则**：只使用当时可知的成交额窗口。建议先比较 20 日成交额中位数的绝对阈值与
   横截面分位阈值，再冻结一个简单规则；阈值不足不靠增加规则数量补救。

涨跌停只按日线能够证明的版本化规则处理：停牌和一字涨/跌停可判为明确不可成交；没有分钟或
盘口证据的普通触及涨跌停日不得臆测成交路径，应保留参考价假设标志。Stage 4 的正式撮合规则
仍须独立验收。

## 完成定义

Stage 2 只有在 [验收矩阵](ACCEPTANCE.md) 全部有实际证据后才能标记完成，最低包括：

- 明确范围内的历史生命周期、ST/`*ST`、退市整理、停牌和复权语义可追溯且无当前状态回填。
- 未来状态或未来公司行动的扰动不改变其生效前的股票池和特征。
- 主/对照标签只读取声明窗口，边界不可成交时产生稳定空值原因；推理读取接口不提供标签。
- 15 个基础因子都有公式、窗口、缺失规则和人工样例；给定父版本可复算相同内容摘要。
- Qlib 全量导出可重建；兼容追加的增量导出与全量结果校准一致，不一致时失败并回退新全量构建。
- 因子研究页能按显式版本查看覆盖、分布、IC、分组收益和相关性，并通过 API/Web/E2E 门禁。
- Alpha158 经同一注册、版本和血缘入口运行，不成为隐藏的第二套生产因子语义。

终验通过只允许申请 Stage 3 授权，不自动开始模型训练。
