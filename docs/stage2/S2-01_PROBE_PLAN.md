## 固定调用清单

提供方仅 BaoStock 0.9.3，已安装 SDK 配置地址为 `public-api.baostock.com:10030`；
执行前核对相同地址并写入首轮日志，不允许替换提供方或端口。
以下证券仅是待验证候选，**尚未确认在所列日期实际发生目标事件**。

| 候选证券 | 固定历史窗口 | 拟观察边界 |
|---|---|---|
| sh.600000 | 2023-01-01..2023-12-31 | 分红/送转索引、复权事件 |
| sz.000001 | 2023-01-01..2023-12-31 | 正常日、公司行动与价格连续性 |
| sz.002309 | 2024-01-01..2024-06-30 | ST 状态变化、退市/停牌候选 |
| sh.688469 | 2023-06-01..2023-07-31 | 上市边界候选 |

每证券依次调用：

1. `query_stock_basic(code=<固定代码>, code_name='')` 一次。
2. `query_history_k_data_plus` 一次，日期见表，`frequency='d', adjustflag='3'`，
   fields 固定为 `date,code,open,high,low,close,preclose,volume,amount,tradestatus,isST`。
3. `query_adjust_factor` 一次，日期见表。
4. `query_dividend_data` 一次，year 为窗口所在年份，`yearType='operate'`。

业务 endpoint 共 16 次，单进程会话 login/logout 各 1 次，总 SDK 调用上限 **18 次**。
不使用 `get_data()` 自动跨页；只消费首个响应页，最多 500 行/响应；发现超过上限或需要分页
立即停止并保留缺口，分页与自动重连均不在预算。记录 SDK 调用数与底层请求数，不混为一谈。

## 超时、输出与停止条件

- 每次 login、业务调用、读取当前响应页、logout 均受父进程 watchdog **30 秒硬超时**；
  到期终止子进程，不依赖 Python 线程取消或供应商 socket 默认行为。
- 全轮墙钟上限 **600 秒**；应用重试 0，自动重连 0。原始输出总上限 5 MiB。
- 第一例网络错误、权限错误、协议/字段漂移、页预算或大小超限、超时即停止；保留已有响应、
  脱敏错误、调用 journal 和失败状态，不生成成功标记。正常零行记录为待解释，不补默认值。
- 输出固定为 `plan.json`、`calls.jsonl`、每调用 `response-01.json` 等原始字段/行、
  `result.json` 和 SHA 清单；调用前记录证券、参数、开始时间，结束记录错误码、行数、耗时。
- 执行器见 [research_probe.py](../../src/quantking/data/adapters/research_probe.py)，
  预算/超时/禁止覆盖及原生 SDK 仿真测试见 [test_research_probe.py](../../tests/data/adapters/test_research_probe.py)。
  离线定向 14 passed；未执行前不创建 a1 证据目录，真实执行只允许使用固定 CLI 开关。
- 参考接口字段由首个合格响应发现，之后同 endpoint 必须一致；日线字段严格匹配请求。
  保留服务端分页容量并要求固定 2000，行数仍不得超过 500。SDK 接收 EOF、部分发送、
  解压尾部或容量漂移立即失败，不补发；额外限制线缆字节累计不超过 5 MiB。
