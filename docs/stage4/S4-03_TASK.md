# S4-03 任务卡：正式回测、最小报告与模型启用

状态：未开始、未授权。

## 目标与依赖

- Stage：4。
- 依赖：S4-01、S4-02 已验收，双引擎固定场景通过。
- 目标：运行一次有界正式 Backtrader 回测，形成决策所需报告，并启用通过验收的模型。
- 正式数据根读取、产物写入和失败重跑分别授权。

## 范围

- dry-run 冻结模型/预测、数据、组合、风险、交易、成本和基准版本，以及日期、证券、输出和预算。
- 将公司行动事实/价格口径版本及执行覆盖检查纳入 dry-run；S4-01/02 的事件守恒校准通过且
  受影响持仓不存在未解决执行缺口后才可正式回测，不从“没有事件记录”推断“没有事件”。
- Qlib 只提供同口径快速参考；正式指标和启用结论以 Backtrader 为准。
- `BacktestRun` 保存每期目标组合、模拟订单/成交/拒绝、日度现金/持仓/净值和完整血缘。
- 计算收益、基准/Top-N 比较、最大回撤、换手、成本、持仓集中度和时间分段结果。没有显式指数
  版本时使用同一动态股票池派生的冻结等权基准，并明确标注为研究基准而非指数。
- 最小报告页展示关键指标、净值/回撤、成本和有界代表性成交/拒绝明细。
- 用户只可对正式回测通过的已批准模型执行“设为使用中”；旧使用中模型自动转为已停用并审计。

## 输出

- 一个正式 Qlib 参考结果、一个正式 Backtrader `BacktestRun` 和差异说明。
- 最小回测报告页、API 和一条模型启用关键 E2E。
- 一个 `使用中` 模型或明确无模型可启用结论。
- `docs/stage4/S4-03_ACCEPTANCE.md` Stage 4 终验记录。

## 测试与验收

- 正式范围与 dry-run 一致，全部父版本、规则和内容 SHA 可复验。
- 失败或缺少关键产物的回测不能启用模型；重复启用幂等，替换动作有审计。
- 报告不隐藏成本、拒绝、缺口或引擎差异，也不选择表现较好的一侧冒充正式结果。
- 页面/API 查询有界，路由不执行回测，完整质量门通过。

## 禁止项

- 不生成 `RebalancePlan`、真实订单或券商文件。
- 不为改善结果调参、改变成本或在同一正式 Job 中重跑。
