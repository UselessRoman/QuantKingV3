## 共同实施规则

- 只实现 ADR-010 的固定 Top 30 基线，不建设优化器、行业约束或多策略框架。
- 交易和风险规则使用普通 Python 纯函数与版本化配置，不建设规则图或 DSL。
- 两个引擎不得重新选股或分配权重；差异只来自显式记录的引擎能力边界。
- 回测复用现有 Job、manifest、日志和原子发布能力，默认单 Job 串行。
- Web 只在 S4-03 增加一个有界报告视图和一条模型启用 E2E。
