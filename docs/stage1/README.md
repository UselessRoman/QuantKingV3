## 授权边界

Stage 1 已获得离线开发授权，但以下操作仍须按任务单独取得明确授权：

- 真实网络访问。
- 读取或下载真实 XTQuant 行情。
- 启动或连接 QMT。
- 写 `E:\QuantKingV3Data`。
- 读写 `E:\QuantKing`（旧项目）。
- 写 `F:\QuantKingV3Backups`。
- 旧项目 `DATA_ONLY` 数据迁移。

一次批准不自动延续到失败后的重试。所有默认离线测试只能使用 pytest 临时目录和合成数据。

## 失败产物纪律

- 失败产物不得原地修复或改成成功。
- 失败目录、日志和输入清单必须保留。
- 修复必须创建新任务和新 ID。
- `PUBLISHED` 数据版本和 `APPLIED` override 不可原地修改或退回。
- `FAILED` 版本和失败批次不能转成成功；重试必须创建新 ID。
