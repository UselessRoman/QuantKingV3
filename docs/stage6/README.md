# Stage 6 文档入口

Stage 6 在系统已经可监督使用的基础上，通过四个连续历史周加速演练、一次实际人工流程和恢复
验证完成运行收口。阶段状态只看 [路线图](../ROADMAP.md)。

## 文档职责

- [任务索引](TASKS.md)：S6-01～S6-02 的顺序和共同边界。
- [S6-01 任务卡](S6-01_TASK.md)：四周加速模拟、故障恢复与性能观察。
- [S6-02 任务卡](S6-02_TASK.md)：人工运行、备份恢复、操作手册与系统终验。
- [验收矩阵](ACCEPTANCE.md)：核心闭环系统验收门禁。

## 阶段边界

- 四个周度周期按连续历史交易周加速回放，不等待四个现实自然周。
- EOD 和周度计划仍由用户手动触发，不建设内部调度器。
- 告警只复用 Web 总览、任务状态和结构化日志，不接入邮件、短信或外部告警平台。
- 备份/恢复复用 Stage 0 能力，只补模型、回测、计划、成交和策略账覆盖。
- 性能只记录是否满足单用户日常使用，不建设基准平台、自动扩缩容或并行调度。

## 主链

```text
四个连续历史周加速回放
  → 重启/中断/部分成交/重复导入恢复
  → 一次用户手动 EOD + 周度计划流程
  → 新增业务数据备份恢复
  → 操作手册与系统终验
```
