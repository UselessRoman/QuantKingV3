## 独立复核重点

- 测试必须导入安装后的 `src` 包，而不是从仓库根目录偶然导入。
- 业务/研究/组合/Web 层不得直接导入受限第三方 SDK；架构边界检查必须自动化。
- 默认离线测试不得访问网络、QMT 或两个正式数据/备份根。
- 真实测试使用显式 marker，并在运行前打印访问对象、路径和副作用。
- `JobEvent` 是低频持久事件，不保存完整日志；SSE 只是传输层。
- SQLite 备份使用在线一致性接口；已完成快照的验证不得生成 WAL/SHM 副产物。
- 增量复制按 manifest/SHA-256 决定，不使用镜像删除。
- 失败产物与日志原样保留，任何失败都阻止完成状态更新。
