## 全阶段禁止项

- 不接入完整历史行情，不创建 Stage 1 数据仓。
- 不计算因子、标签或股票池，不训练模型，不实现回测或组合业务。
- 不连接真实或模拟交易账户，不定义或调用下单、撤单能力。
- 不从 `E:\QuantKing` 复制业务代码、目录或运行数据。
- 默认测试不得访问网络、QMT、`E:\QuantKingV3Data` 或 `F:\QuantKingV3Backups`。
- 不把失败任务或失败备份修补成成功；失败产物、日志和输入清单必须原样保留，修复使用新任务和新输出。
- Stage 1 尚未获准开始；不得把 Stage 1 及以后目标能力描述为已经可用。

## 外部授权边界

以下动作必须按对应任务取得明确授权，并在命令执行前展示访问对象、目标路径和副作用：

- 下载或安装稳定 Python 3.12、`uv`、Node.js 及 PyPI/npm 依赖。
- 真实 XTQuant 只读探针；若需要启动或连接 QMT，必须再次说明范围并单独授权。
- 创建或写入 `E:\QuantKingV3Data`。
- 创建或写入 `F:\QuantKingV3Backups`，以及真实恢复演练。

一次批准不自动延续到失败后的重试。仓库内离线实现、临时目录合成测试和对 `E:\QuantKing` 的只读清单审计不扩大这些授权。

## 交付纪律

- 每张任务卡由专门开发 agent 执行；只实现该卡，不预建后续功能。
- 先写会失败的测试或检查，再实现，再运行任务卡门禁。
- agent 必须报告修改文件、测试命令、结果和未解决风险；自报完成不是验收结论。
- 主 agent 独立检查差异、架构边界和测试证据。发现问题时回到同一任务卡修复，不跨卡掩盖。
- 正式外部验收失败时立即停止该验收，保留失败目录，不更新完成状态；重试需新授权。
