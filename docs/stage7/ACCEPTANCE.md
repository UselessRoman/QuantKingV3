# Stage 7 单域验收矩阵

状态：模板基线，未授权、未开始。该矩阵对每个独立数据域实例重复执行；一个域通过不代表其他域
已支持。

## A. 价值、范围与来源

- [ ] 有一个明确的研究、风险或 Web 消费方，且缺少该域确实阻碍当前决策。
- [ ] 市场、证券、日期、字段和排除项有有界清单，不采集供应商全部字段。
- [ ] 来源许可、稳定性、历史深度、单位、披露/可用时间、修订和空结果已用真实小样本验证。
- [ ] 来源不可得或 point-in-time 无法证明时停止，不以当前值回填历史。

## B. 数据合同与发布

- [ ] schema、主键、单位、可用时间、修订、缺失和质量规则可执行且有固定样例。
- [ ] 新适配器位于数据适配层，第三方异常转换为稳定错误。
- [ ] 复用现有 Raw、Canonical、Job、manifest、临时目录和原子发布能力，无平行控制面。
- [ ] 有界正式 `DatasetVersion` 可复验父血缘、范围、行数、内容 SHA 和缺口。
- [ ] 未来披露或供应商修订不会原地改变已发布历史版本。

## C. 首个消费方

- [ ] 只有显式版本进入研究/风险消费方，不读取隐式 latest。
- [ ] point-in-time 和未来扰动测试覆盖实际消费语义。
- [ ] 一个有界 API/页面或离线报告证明数据产生预定价值，不建设通用仪表盘。
- [ ] 未覆盖域、市场、日期和字段在 UI/文档中显式可见。

## D. 单域关闭

- [ ] 后端、必要前端/E2E、Markdown 和完整质量门通过。
- [ ] 域级 `S7-03_ACCEPTANCE_<domain>.md` 记录实际来源、范围、产物、消费方和限制。
- [ ] 只把该域标记为可用；其他候选域状态不变，也未自动授权。
