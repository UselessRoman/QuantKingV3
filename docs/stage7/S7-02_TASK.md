# S7-02 任务卡：有界数据版本实现与发布

状态：按需、未开始、未授权。

## 目标与依赖

- Stage：7。
- 依赖：对应数据域的 S7-01 已验收。
- 目标：只为冻结范围实现适配、质量和版本发布，形成一个可追溯 `DatasetVersion`。

## 范围

- 实现冻结来源适配器、Canonical schema、质量规则和必要的来源交叉检查。
- 保存 Raw、来源/披露时间、修订标识和原始单位；标准化转换可追溯。
- 使用现有 Job、manifest、临时目录、`COMPLETE` 和原子发布服务。
- 正式 dry-run 固定调用、超时、预算、范围、输出路径和预期产物；真实操作单独授权。
- 提供显式版本的覆盖、缺口、质量摘要和有界明细查询，本任务不建设专用页面。

## 输出

- 单域适配器、schema、质量和发布实现。
- 合成发布/失败/幂等证据及获授权后的一个正式有界 `DatasetVersion`。
- `docs/stage7/S7-02_ACCEPTANCE_<domain>.md`。

## 测试与验收

- schema、单位、可用时间、修订、空结果和异常合同测试通过。
- 当前值/未来披露扰动不改变历史 point-in-time 结果。
- 失败不发布半成品，相同输入内容幂等，已发布目录不可修改。
- 正式范围与授权一致，manifest、文件集合、行数、SHA 和缺口可复验。

## 禁止项

- 不采集未冻结字段，不同时扩展第二个域。
- 不实现研究模型、风险规则或页面消费，不建设第二套任务/发布控制面。
