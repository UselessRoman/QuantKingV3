# S7-01 任务卡：数据域选择、价值确认与来源资格

状态：按需、未开始、未授权。

## 目标与依赖

- Stage：7。
- 依赖：Stage 6 已完成；用户明确提出一个数据域和消费需求。
- 目标：在编码前证明该数据域值得建设且可以满足 point-in-time 要求。

## 范围

- 从历史指数成分、行业、估值或财务中只选择一个域，写明唯一首个消费方和决策价值。
- 冻结最小字段、市场/证券、日期、预估行数和排除项；不请求供应商全量字段。
- 对候选来源做有界真实探针，验证许可、稳定性、历史深度、单位、主键、可用时间和修订行为。
- 评估权威来源、交叉检查和冲突策略；point-in-time 无法证明时形成阻断结论。
- 建立可人工核对的正常、缺失、修订、边界和未来扰动 fixture。

## 输出

- 数据域价值说明、范围 manifest、来源资格报告和 schema 草案。
- 实际探针证据及 `docs/stage7/S7-01_ACCEPTANCE_<domain>.md`。

## 测试与验收

- 消费方、最小字段和成功指标明确；删除该域会明确阻碍目标功能。
- 来源探针真实、范围有界、调用和输出可复验，未写正式数据根。
- 可用时间和修订策略足以防止当前值回填历史。
- 资格失败时停止，不先建设适配器、通用 schema 或页面。

## 禁止项

- 不同时评估或实现多个数据域。
- 不发布正式版本，不读取旧项目，不建设通用数据平台。
