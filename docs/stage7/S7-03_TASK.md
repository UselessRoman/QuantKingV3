# S7-03 任务卡：首个消费方接入与单域验收

状态：按需、未开始、未授权。

## 目标与依赖

- Stage：7。
- 依赖：对应数据域的 S7-02 已验收并存在正式有界版本。
- 目标：把该域接入 S7-01 冻结的唯一消费方，证明数据产生实际价值后关闭本次单域交付。

## 范围

- 消费方显式接收数据版本和最小字段，不允许深层选择 latest。
- 为实际用例实现必要的 point-in-time join、缺失/冲突处理和未来扰动测试。
- 优先复用现有数据/研究/风险工作区，只增加一个有界摘要或明细，不新建通用仪表盘。
- 执行一次正式消费任务或报告，记录输入、输出、业务结论和未覆盖范围。
- 更新该域文档和状态；其他候选域保持未开始。

## 输出

- 一个实际消费用例、必要 API/页面或离线报告及测试。
- `docs/stage7/S7-03_ACCEPTANCE_<domain>.md` 单域终验记录。

## 测试与验收

- 不使用未来披露、未来成分或当前分类回填历史。
- 数据缺失、冲突或版本不兼容时消费方失败关闭或明确降级。
- 页面/API 有界且不返回供应商载荷或全市场矩阵。
- 完整质量门通过，验收只声明冻结域/范围/消费方可用。

## 禁止项

- 不顺带增加第二消费方、第二数据域或通用特征平台。
- 不自动开始下一数据域，不反向改变 Stage 0～6 已发布产物。
