# Stage 7 文档入口

Stage 7 是核心闭环完成后的按需扩展阶段。每次只选择一个有明确消费方的数据域，完成小范围来源
资格、版本化发布和首个消费验收；其他域继续保持未开始。阶段状态只看 [路线图](../ROADMAP.md)。

## 文档职责

- [任务索引](TASKS.md)：可重复单域交付循环和共同边界。
- [S7-01 任务卡](S7-01_TASK.md)：数据域选择、价值确认与来源资格。
- [S7-02 任务卡](S7-02_TASK.md)：有界数据版本实现与发布。
- [S7-03 任务卡](S7-03_TASK.md)：首个消费方接入与单域验收。
- [验收矩阵](ACCEPTANCE.md)：每个数据域实例的门禁。

## 阶段边界

- Stage 7 不属于首次可监督使用或核心产品系统验收的阻断项。
- 财务、估值、行业和历史指数成分分别立项，不一次建设全部域。
- 每个域必须有一个当前消费方；没有消费方时不建 schema、适配器、页面或通用平台。
- 新来源重新验证许可、字段、单位、历史深度、point-in-time、修订和质量语义。
- 复用现有 Raw/Canonical/版本/manifest/Job/发布能力，不建设第二个数据平台。
- 单域完成只声明该域和冻结范围可用，不推断其他域或全部市场已经支持。

## 单域主链

```text
明确消费需求
  → 小范围来源资格
  → 有界 DatasetVersion
  → 一个研究/风险/Web 消费方
  → 单域验收
```
